Built for serious builders

For engineers who want an agent to ship whole features and still read every diff before it merges. If you want autocomplete, this is too much process. If you want a process, it's the right amount.

  • Control

    Pause, stop or resume any run. Anything that edits, tags or pushes waits for your confirmation.

  • Transparency

    Every phase leaves a named artifact you can open. Every instruction file the agent saw is recorded by hash.

  • Reproducibility

    Same pipeline, same gates, every run. Each run works from a written spec you can read before any code changes.

  • Structured workflows

    Big work splits into dependency-ordered subtasks. Each gets a fresh context and exactly one commit.

  • Extensibility

    Platform packs, add-ons, per-phase instructions and your own skills, all written as plain source files.

  • Reliability

    A repair round that doesn't close gaps stops the run and says why. Failing CI gets repaired, not ignored.

Local-first. Developer-controlled.

The runtime, your specs and every run's history stay on your disk. It uses your agent CLI, your credentials and your repository. There's no account to create and no server you depend on.

Manifesto

  1. No vendor lock-in.

    Four agents, one runtime. Switch halfway through a run.

  2. No disposable context.

    State lives on disk, not in a chat window.

  3. No chaos disguised as intelligence.

    Every phase has a contract, a gate and an artifact.

  4. Serious engineering.
    Zero bullshi*t.

Fast forward development.
